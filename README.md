# 네이버 블로그 초안 자동화

내가 정한 주제를 넣으면, Claude가 최신 정보를 웹 검색으로 확인해서 네이버 블로그 글 초안을 써 줘요.
주제를 밖에서 자동으로 가져오지 않아요. 내가 넣은 주제로만 써요.

발행은 직접 해요. 네이버 블로그는 글쓰기 API가 없어서, 만들어진 글을 붙여넣고 네이버의 **예약 발행** 기능으로 시간을 정하면 돼요.

## 처음 한 번만 설정

1. [Anthropic Console](https://console.anthropic.com)에서 API 키를 만들고 크레딧을 충전해요.
2. 이 저장소의 **Settings → Secrets and variables → Actions → New repository secret**에서
   이름 `ANTHROPIC_API_KEY`, 값에 API 키를 넣어 저장해요.

## 글 만들기

1. **Actions** 탭 → 왼쪽 **블로그 초안 만들기** → 오른쪽 **Run workflow**를 눌러요.
2. **글 주제** 칸에 쉼표로 구분해서 적어요.
   ```
   다이소 수납템 추천, 환절기 비염 관리법, 제주도 겨울 여행코스
   ```
3. 창 안의 초록색 **Run workflow**를 눌러요. 주제 하나에 1~3분 정도 걸려요.
4. 끝나면 `posts/날짜/` 폴더에 글이 생겨요.

> 예전 실행 기록에서 **Re-run**을 누르면 그때의 옛날 코드로 다시 실행돼요. 항상 **Run workflow**로 새로 실행해 주세요.

같은 날 여러 번 실행하면 `posts/2026-11-10-2/`처럼 새 폴더에 저장돼서 앞의 글이 지워지지 않아요.

## 글이 만들어진 다음 할 일

`posts/날짜/README.md`를 열면 글 목록과 예약 시간이 표로 정리되어 있어요.

1. `post.md`를 읽고, **내 경험이나 의견을 한두 문단 더해요.** (AI 글을 그대로 올리면 네이버 검색에서 저품질로 판정받기 쉬워요.)
2. 네이버 블로그 글쓰기에서 제목을 넣고 본문을 붙여넣어요.
   - 서식(소제목, 표)을 살리려면 `post.html`을 내려받아 브라우저로 열고, 본문을 드래그해서 복사하면 돼요.
3. 태그를 넣고, 발행 버튼 옆 **예약**에서 추천 시간으로 설정해요.
4. 본문의 `[이미지: ...]` 표시 자리에 어울리는 사진을 넣으면 더 좋아요.

> 글 아래 **참고 자료** 링크로 숫자나 날짜 같은 사실을 한 번 확인한 뒤 발행해 주세요.

## 글쓰기 규칙

- 친근한 존댓말, 본문 2,000~3,000자, 소제목 3~5개
- 날짜, 가격, 일정 같은 사실은 웹 검색으로 확인한 것만 써요
- **건강/의학**: 효과를 단정하지 않고 일반 정보로 쓰고, 끝에 전문의 상담 안내를 넣어요
- **쇼핑·할인**: 가격과 행사 기간은 기준 날짜와 함께 적어요
- **여행**: 운영 시간, 요금, 축제 일정은 방문 전 공식 안내를 확인하라고 적어요

규칙은 `blog_auto/writer.py`에서 바꿀 수 있어요.

## 설정 바꾸기

저장소 **Settings → Secrets and variables → Actions → Variables** 탭에서 아래 이름으로 값을 넣으면 바뀌어요. 넣지 않으면 기본값을 써요.

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PUBLISH_TIMES` | `08:00,19:00` | 예약 발행 추천 시간 (글 순서대로 돌아가며 붙음) |
| `BLOG_MODEL` | `claude-sonnet-5-5` | 사용할 Claude 모델 (`claude-opus-5-5`는 품질이 더 좋지만 비용이 약 2배) |

## 비용

글을 쓸 때 Claude API를 쓰고, 그때만 Console 크레딧이 나가요. 실행하지 않으면 비용이 없어요.
글 1편에 대략 0.3달러 정도로 예상해요. 대부분 웹 검색 결과가 Claude 입력에 들어가서 생기는 비용이에요.
실제 금액은 Console의 Usage 화면에서 확인하세요.

## 내 컴퓨터에서 실행하기

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=내-API-키
python -m blog_auto.main --topics "다이소 수납템 추천, 환절기 비염 관리법"
python -m blog_auto.main --dry-run   # API 없이 결과물 모양만 확인
```

## 파일 구조

```
blog_auto/
  topics.py     입력한 주제 정리
  writer.py     글 초안 쓰기 (Claude + 웹 검색)
  claude.py     Claude API 호출
  main.py       전체 순서 실행, posts/ 폴더에 저장
posts/날짜/     만들어진 글
```
